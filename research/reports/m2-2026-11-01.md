# M2: شبکهٔ پیاده و وابستگی خیابان–اتصال مسیر

تاریخ: ۱ نوامبر ۲۰۲۶. ورودی، همان توزیع عمومی OSM-only است؛ دادهٔ بیرونی اضافه نشده است.

## نتیجهٔ اجرا

| خروجی | تعداد |
|---|---:|
| wayهای نامزد پیاده | 206,474 |
| یال‌های بدون جهت پیاده پس از شکستن در نقاط اتصال | 930,852 |
| ساختمان با اتصال هندسی حداکثر ۱۰۰ متر | 64,166 از 65,677 |
| عارضهٔ بیمارستان انسانی با اتصال هندسی حداکثر ۱۰۰ متر | 241 از 249 |
| ارتباط توقف–مسیر دارای اتصال هندسی | 443 |
| اتصال متوالی اتوبوس | 138 |
| اتصال متوالی ریلی | 280 |
| رخدادهای وابستگی قطعه در اتصال‌های اتوبوس | 1,895 |
| قطعات منبع یکتای مورد استفاده در وابستگی‌ها | 1,684 |
| ارتباط توقف–مسیر دارای محدودیت سوار/پیاده‌شدن | 16 |

۱٬۵۱۱ ساختمان و هشت عارضهٔ بیمارستان بیش از سقف فاصله بودند؛ حذف از دادهٔ خام رخ نداده و وضعیتشان ثبت شده است. ۴۴۳ تعداد ارتباط توقف–مسیر است، نه ایستگاه فیزیکی یکتا. هر قطعه با way و جفت گره‌های مجاور منبع شناخته می‌شود؛ معادل خیابان نام‌گذاری‌شده یا سازهٔ فیزیکی یکتا نیست.

۱۱ relation اتوبوس و ۱۴ ریلی در این نسخه استفاده شدند. ۲۸ relation اتوبوسِ دارای اختلاف ترتیب توقف همچنان در بازبینی‌اند. برای آن‌ها شمار گام‌های عقب‌گرد و نوع بازنمایی توقف ثبت شد؛ ترتیب اعضا خودکار عوض نشد.

## کنترل‌ها

- یازده آزمون کوچک الگوریتمی موفق بودند.
- SQLite سالم، طول منفی صفر و اتصال هندسی پذیرفته‌شدهٔ فاقد رأس متناظر در شبکه صفر بود.
- برای همهٔ اتصال‌های اتوبوس، مجموع طول بازه‌های وابستگی با طول اتصال روی مسیر ثبت‌شده مطابق بود.
- هیچ وابستگی یتیم، وابستگی ریلی در جدول اتوبوس یا بازهٔ با همپوشانی غیرمثبت پیدا نشد.
- قیدهای فقط سوار/فقط پیاده با نقش منبع تطبیق داده شدند.
- در نمونهٔ مستقل ۲۰ way، مجموع طول یال‌های شکسته‌شده با طول هندسهٔ منبع پس از تبدیل مختصات برابر بود. این کنترل نمونه‌ای است؛ کنترل مستقل همهٔ wayها ادعا نمی‌شود.

## حدود تفسیر

این اعداد، پوشش اتصال هندسی با سقف سناریویی ۱۰۰ مترند؛ دسترسی واقعی یا حتی امکان رسیدن به بیمارستان در مدل سفر نیستند. گراف وجود دارد اما حل‌گر دارای حالت خط/تعویض و بودجهٔ کل پیاده هنوز پیاده‌سازی نشده است.

پیوند مستقیم هندسی، ورودی و عبور از مانع را تأیید نمی‌کند. در تساوی فاصلهٔ نزدیک‌ترین راه، یک نامزد STRtree انتخاب شده و حساسیت آن باید بررسی شود. مجموع طول و هویت گره‌های منبع حفظ شده‌اند؛ تقاطع هم‌مختصاتِ فاقد اتصال منبع به اتصال مصنوعی تبدیل نشده است.

## بازتولید

```bash
python -m unittest discover -s tests -v
python -m research.src.extract_routes
python -m research.src.build_connections
python -m research.src.audit_connections
```

خروجی کامل زیر `research/model/m2-v2/` نگهداری می‌شود و عمداً وارد Git نشده است. خروجی موجود بازنویسی نمی‌شود؛ برای اجرای مستقل ساخت، `--output research/model/<new-run>` قابل استفاده است. فرمان audit فعلی به مسیر پایهٔ `m2-v2` اشاره دارد. JSON خلاصه و ممیزی این اجرا در همین پوشهٔ reports ثبت شده‌اند.

گام بعدی، حل‌گر اتصال با بودجهٔ تجمعی پیاده، شمارش تعویض خط و رعایت نقش‌های سوار/پیاده است؛ سپس می‌توان پوشش واقعی خط پایه و آزمایش‌های اختلال را محاسبه کرد.
